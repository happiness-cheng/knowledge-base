## 学习时间权重

### 2026-09-03 冲刺期裁剪（依据行业调研）

> 面试窗口：9月中旬起笔试/一面，10月中旬主力出结果。可用时间约 4-5 周。
> 调研结论：大厂 Agent 岗高频考点 = RAG全链路+调优排查、混合检索、MCP vs Function Calling、ReAct/Plan-and-Execute、Agent评测、多轮tool call状态管理、中间状态持久化、手撕Agent循环。工程能力权重 60-70%，AI 知识 30-40%。

| 冲刺优先级 | 模块 | 理由 |
| ---------- | ---- | ---- |
| S1 必考 | M5 RAG（裁剪到核心12点）、M4 工具调用（含MCP）、M11 项目与系统设计 | 面试出现率最高；项目是后端背景差异化武器 |
| S2 高频 | M3 架构（已学完需重新激活）、M7 评估（RAGAS/评测集）、M2 Context Engineering | 美团/字节真题直接命中 |
| S3 补齐 | M1 LLM基础（重新激活即可）、M6 Memory（状态持久化真题相关） | 已有基础，快速回顾 |
| 降低 | M9 框架（LangGraph 只学核心概念+选型对比）、M8（并入M4/M11按需学） | 面试考概念不考深度 |
| 移出冲刺 | M10 多Agent（降为概念级）、M9-32~37 Docker/CI/SSE细节 | 时间不够，P2 |

```python
calculator(expr: str) -> str  # 计算数学表达式
```

